# বাজার দর / BazarDor

## Short Description
**বাজার দর (BazarDor)** is a modern, responsive commodity price tracking web application for Bangladesh. Powered by a live commodity API, the platform provides daily market price updates, division-wise price comparisons, and market trend analysis for everyday essentials like rice, lentils, oil, vegetables, meat, and spices.

---

## Technologies Used
- **Next.js 16** (App Router, Turbopack, Server Components)
- **React 19**
- **Tailwind CSS v4**
- **MongoDB Atlas**
- **Better Auth** (Google OAuth, GitHub OAuth, Email/Password)
- **Lucide React** (Icons)
- **React Hot Toast** (Notifications)
- **Bazar Dor Live API** (Data Source)

---

## 5 Key Features of the Project

1. **Live Dynamic Price Ticker**: A continuous marquee ticker showing real-time commodity prices and daily price fluctuation trends (increases and decreases).
2. **Market Movers (Top Risers & Fallers)**: Automated daily highlights of commodities with the highest price jumps and steepest drops.
3. **Commodity Directory & Category Filtering**: Instant commodity search by name, category-based filtering (Rice, Lentils, Oil, Vegetables, Meat & Fish, Spices), and price sorting (Low to High / High to Low).
4. **Protected Commodity Analytics & Divisional Breakdown**: Server-side protected product details featuring lowest, highest, and average pricing alongside a division-wise price comparison table across all 8 divisions of Bangladesh.
5. **Full Bengali Localization & Persistent Authentication**: Complete Bengali digit, unit, and currency formatting with zero-flicker navbar session hydration on page refresh and social authentication via Google and GitHub.
